# Claude Code Plugin

Expert knowledge for Claude Code features, setup, and best practices.

## Overview

The Claude Code plugin provides comprehensive guidance on:
- **Setup & Configuration** - Installation, settings, CLAUDE.md
- **Slash Commands** - Built-in and custom commands
- **MCP Integration** - Model Context Protocol servers
- **Hooks & Plugins** - Extending Claude Code functionality
- **IDE Integration** - VS Code, JetBrains, Vim/Neovim
- **Enterprise Features** - Teams, permissions, deployment

## Installation

```bash
cp -r my-plugins/plugins/claude-code ~/.claude/plugins/
```
